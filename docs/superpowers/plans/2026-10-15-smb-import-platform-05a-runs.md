## Виміри платформи (Step 3; тест `СМП_ТестыКоннекторовОбщее`, 41 кейс, зелений на виміряному)

Умова виміру: платформа 8.3.27.2342, файлова база, `ЧасовойПоясСеанса()` = `Europe/Kiev`
(два тести-«умови» червоніють, якщо інакше). Пояс сеансу в тестах не змінювався.

- **Ім'я пояса (D36 п. 7):** приймається `Europe/Kiev`; `Europe/Kyiv` відхиляється
  (`Ошибочный идентификатор часового пояса 'Europe/Kyiv'`); серед 620 допустимих є `Europe/Kiev`, немає `Europe/Kyiv`.
- **`МестноеВремя(UTC, "Europe/Kiev")`:** зима — 22:00:00 UTC → 00:00:00 місцевого, **22:30 UTC → 00:30**;
  літо — 21:00:00 UTC → 00:00:00, **21:30 UTC → 00:30**. Перехід 2026-03-29: 00:59:59 UTC → 02:59:59,
  01:00:00 UTC → 04:00:00 (години 03:xx немає). Перехід 2026-10-25: 00:59:59 UTC → 03:59:59, 01:00:00 UTC →
  03:00:00; 00:30 UTC і 01:30 UTC обидва → 03:30 (місцевий час не визначає момент однозначно).
- **Довжина місцевої доби:** 2026-03-29 — 23 год; 2026-10-25 — 25 год; звичайні — 24 год.
- **Обернене:** `УниверсальноеВремя(03:30 10-25, "Europe/Kiev")` = 01:30 UTC (повторювана година — друге,
  зимове входження); 03:30 03-29 (години немає) = 01:30 UTC; 02:30 03-29 = 00:30 UTC.
- **`МестноеВремя(Д)` попередника (одним параметром):** збігається з явним поясом для 00:30 узимку, 00:30
  влітку й для двох переходів — за умови, що пояс сеансу `Europe/Kiev`. Для іншого поясу сеансу не міряно.
- **`Строка()` від відсутнього ключа `Соответствие`:** ключ дає `Неопределено`; `Строка(Неопределено)` і
  `Строка(Null)` — порожній рядок, не слово.
- **Додатково (ланцюжок ключа D17):** `Дата("07.01.2020 02:58:00")` і `Дата("07.01.2020 2:58:00")` =
  2020-01-07 02:58:00; `Дата("07.01.2020")` — виняток (`Преобразование значения к типу Дата не может быть
  выполнено`); `Строка(Дата)` — `15.10.2026 0:30:12` (година без нуля); `Число("0.01")` = 0.01,
  `Число("12,5")` = 12.5; `Формат(1234.56, "ЧГ=0")` = `1234,56`, `Формат(0.5, "ЧГ=0")` = `0,5`.
- **Мутація без коміту:** змінено очікування пояса сеансу (на UTC) і неоднозначної години (01:30 → 00:30) —
  рівно ці два кейси червоні (39/41); повернуто, повторний прогін зелений.

## Процес: подвійні прогони

Помилка виконавця. Прогін усіх модулів запущено скриптом через `nohup` у фоні; оболонка повідомила про
завершення одразу, а `summary.txt` не з'явився, тож я вирішив, що запуск не відбувся, і запустив той самий скрипт
удруге (видаливши `summary.txt`). Перший запуск при цьому працював (процес `v8-runner` стартував 21:00:30).
Другий упирався в блокування робочої теки (`workspace ... is already locked by 'test'`) і за секунди пройшов
усі модулі з помилкою `ERROR: runtime error: cannot start test`, переписавши `mods/*.txt`; потім перший запуск
послідовно по одному модулю перезаписав ці файли справжнім виводом. Два прогони платформи одночасно на одну базу
**не виконувались**: блокування другий не пустило, тож базі нічого не заважало. Результати вважаються
цілими, бо: (а) кожен із 32 виводів має рядок `summary` справжнього прогону (перевірено переглядом усіх);
(б) числа відтворюють етап 7 для модулів, що були тоді; (в) `СМП_ТестыВендораЗаполнениеДокумента` — перший

### Пауза транспорту через фонове завдання

Платформа не має виклику очікування. Цикл по `ТекущаяУниверсальнаяДата` завантажував би процесор, тож
взято прийом попередника (`СМП_РаботаСБанкамиМонобанкAPIСервер.Пауза`, за зразком БСП): фонове
завдання очікує саме себе. У фоновому завданні `ПолучитьТекущийСеансИнформационнойБазы().ПолучитьФоновоеЗадание()`
повертає поточне завдання, і воно чекає `ОжидатьЗавершенияВыполнения(Секунды)`; поза фоновим контекстом
запускається допоміжне завдання на той самий метод і викликач чекає на нього не довше за паузу. Ціль
завдання — експортний метод загального модуля, звідси окремий `СМП_ТранспортHTTPСервер` (методом
обробки завдання не запустити). Обмеження: фонові завдання — лише сервер, модуль для клієнта
недоступний (флаг `Сервер`, клієнтські контексти вимкнені), тож виклик паузи з клієнта (форма, веб-клієнт)
не знайде методу й не скомпілюється; транспорт розрахований на регламент (етап 5б). У цьому процесі справжня
пауза не вимірювалась (тести справжній транспорт не створюють): лише syntax і рев'ю коду.
