# monobank ФОП і ТОВ — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Додати до розширення `SMP_BankExchange_SMB` другий режим monobank для ТОВ (API юросіб) і виправити чинний режим ФОП: дедуплікація за ідентифікатором транзакції, UTC, пагінація, ліміти, регламентний обмін із курсором, безпечна синхронізація-видалення.

**Architecture:** Два незалежні серверні модулі «модуль на банк» — чинний `СМП_РаботаСБанкамиМонобанкAPIСервер` (ФОП, `api.monobank.ua/personal`) переписується всередині, новий `СМП_РаботаСБанкамиМонобанкЮрAPIСервер` (ТОВ, `corp-api.monobank.ua/ext/v1`) додається поруч. Обидва повертають одну структуру результату читання (транзакції, ознака повноти, час останньої завантаженої й першої пропущеної) і обидва прогоняють рядки через спільний розпізнавач `Обработки.СМП_КлиентБанк.РаспознатьДанныеВСтрокеДокумента`, де додається пошук документа за новим реквізитом `СМП_ИДТранзакцииБанка`. Диспетчер регламенту `СМП_РаботаСБанкамиСервер.ОбменСБанком` отримує дві гілки.

**Tech Stack:** 1С:Підприємство 8.3.27, розширення в форматі Designer platform XML, BSL, `КоннекторHTTP_BankExchange` (вже в розширенні), Unica MCP для валідації/збірки/синтаксису, git.

**Spec:** `docs/superpowers/specs/2026-09-15-monobank-fop-tov-design.md` (далі — «спека», посилання на її розділи як §N). Карта API: `docs/banks/monobank-api-map.md`.

## Global Constraints

- Продукт — лише `SMP_BankExchange_SMB`. SMBru і ACC не чіпати (§10).
- Формат вихідників — Designer platform XML, версія формату `2.20`; платформа `8.3.27.x`. EDT не використовується.
- Сховище конфігурації — тільки читання; `git push` і PR — лише за явним проханням (CLAUDE.md).
- Усі застосовні операції Unica (`dryRun: false`) і `kit … -Apply` — з названим ризиком; у межах цього плану виконавець **один раз на старті** просить дозволу завантажувати розширення в базу агента (`operation=build`) після кожної задачі.
- Персональне API: ліміт **1 запит на 60 с на функцію**; максимум **500** записів на відповідь, ознаки продовження немає; максимальний період **31 доба + 1 година = 2 682 000 с** (§5).
- API юросіб: `limit` **передавати завжди** (типово 10, максимум 500); заголовки `x-token` і **обов'язковий** `accept: application/json`; ліміти — заголовки `x-rate-limit-remaining` і `x-rate-Limit-retry-after-seconds` (§6).
- Вантажимо: ФОП — лише `hold = false`; ТОВ — лише `status = "DONE"` (§5, §6).
- Синхронізація-видалення: ТОВ — лише коли всі завантажені дати `isFinal = true` **і** виписка повна; ФОП — **ніколи** (§7).
- Курсор: на час останньої завантаженої транзакції, але не далі за найранішу пропущену `hold`/`PENDING`; за неповного читання курсор не просувається (§8).
- Довжини: `СМП_ИДТранзакцииБанка` — рядок 50, індексований; ресурс `ИДТранзакции` регістру — 20 → 50 (§4).
- Призначення платежу — не довше 255 символів, обрізання з кінця (§5).
- Новий реквізит заповнюється і використовується для пошуку **лише** рядками, у яких монобанк-модулі заповнили `ИДТранзакцииБанка`; для решти банків поведінка не змінюється (§4).
- Mova коду — як у сусідніх модулях: ідентифікатори й коментарі російською, `НСтр` із варіантами `ru` і `uk`. Коментарі-маркери змін у чужому коді обробки — `//СМП_РаботаСБанками +++` / `//СМП_РаботаСБанками ---`, як уже прийнято в `ManagerModule.bsl`.

```bsl
		КонецЕсли;
		СтрокаДокумента.НазначениеПлатежа = СокрЛП(СтрокаДокумента.НазначениеПлатежа);
		СтрокаДокумента.НомерКартинки = ?(ПустаяСтрока(СтрокаДокумента.ОписаниеОшибок), 0, 1);
	КонецЦикла;

// загружать было нечего), но не позже самой ранней пропущенной hold-транзакции.
// При неполном чтении — пустая дата: курсор не двигаем, следующий запуск перечитает период.
//
Функция ДатаКурсора(РезультатЧтения, КонецПериода)
	
	Если Не РезультатЧтения.Полная Тогда
		Возврат Дата(1, 1, 1);
	КонецЕсли;
	
	Если ЗначениеЗаполнено(РезультатЧтения.ВремяПоследнейЗагруженной) Тогда
		Результат = РезультатЧтения.ВремяПоследнейЗагруженной;
	Иначе
		Результат = КонецПериода;
	КонецЕсли;
	
	Если ЗначениеЗаполнено(РезультатЧтения.ВремяПервойПропущенной)
		И РезультатЧтения.ВремяПервойПропущенной < Результат Тогда
		Результат = РезультатЧтения.ВремяПервойПропущенной;
	КонецЕсли;
	
	Возврат Результат;
	
КонецФункции

```

```bsl
// Читает транзакции API юрлиц за период: страницы по 500 (limit передается всегда — по умолчанию банк отдает 10),
// сдвиг верхней границы при полной странице, учет лимитов по заголовкам ответа.
// Загружаются только status = DONE; PENDING запоминается как пропущенная (для курсора), DECLINED и reverse пропускаются.
//
// Параметры:
//   Сессия - Структура - см. НоваяСессия.
//   НомерСчетаIBAN - Строка
//   НачалоПериода, КонецПериода - Дата - местное время.
//
// Возвращаемое значение:
//   Структура - как у СМП_РаботаСБанкамиМонобанкAPIСервер.ПрочитатьТранзакции:
//     Транзакции, Полная, ИДПоследнейЗагруженной, ВремяПоследнейЗагруженной, ВремяПервойПропущенной, Ошибки,
//     плюс ДатыЗагруженных - Массив из Дата - начала суток (местное время) загруженных транзакций.
//
Функция ПрочитатьТранзакции(Сессия, НомерСчетаIBAN, НачалоПериода, КонецПериода)
	
	Результат = Новый Структура;
	Результат.Вставить("Транзакции", Новый Массив);
	Результат.Вставить("Полная", Истина);
	Результат.Вставить("ИДПоследнейЗагруженной", "");
	Результат.Вставить("ВремяПоследнейЗагруженной", Дата(1, 1, 1));
	Результат.Вставить("ВремяПервойПропущенной", Дата(1, 1, 1));
	Результат.Вставить("Ошибки", Новый Массив);
	Результат.Вставить("ДатыЗагруженных", Новый Массив);
	
	ДобавленныеИдентификаторы = Новый Соответствие;
	ДобавленныеДаты = Новый Соответствие;
	ВерхняяГраница = КонецПериода;
	
	Пока Истина Цикл
		
		URL = СтрШаблон("https://corp-api.monobank.ua/ext/v1/statement/%1/%2/%3?limit=%4",
			НомерСчетаIBAN, ДатаВремяВUnixTime(НачалоПериода), ДатаВремяВUnixTime(ВерхняяГраница), РазмерСтраницы());
		Ответ = ВыполнитьЗапросСУчетомЛимита(Сессия, URL);
		
		Если Ответ.КодСостояния <> 200 Тогда
			Результат.Полная = Ложь;
			Результат.Ошибки.Добавить(ОписаниеОшибкиОтвета(Ответ, ПредставлениеПериода(НачалоПериода, ВерхняяГраница)));
			Возврат Результат;
		КонецЕсли;
		
		Страница = КоннекторHTTP_BankExchange.КакJson(Ответ);
		Если ТипЗнч(Страница) <> Тип("Массив") Тогда
			Результат.Полная = Ложь;
			Результат.Ошибки.Добавить(НСтр("ru = 'monobank (юрлица): изменился формат получаемых данных. Обратитесь к разработчику.'; uk = 'monobank (юрособи): змінився формат отримуваних даних. Зверніться до розробника.'"));
			Возврат Результат;
		КонецЕсли;
		
		ВремяСамойРанней = Неопределено;
		Для Каждого Транзакция Из Страница Цикл
			
			ВремяСоздания = ДатаИзUnixTime(Транзакция["time"]);
			Если ВремяСамойРанней = Неопределено Или ВремяСоздания < ВремяСамойРанней Тогда
				ВремяСамойРанней = ВремяСоздания;
			КонецЕсли;
			
			Статус = Строка(Транзакция["status"]);
			Если Статус = "PENDING" Тогда
				Если Не ЗначениеЗаполнено(Результат.ВремяПервойПропущенной)
					Или ВремяСоздания < Результат.ВремяПервойПропущенной Тогда
					Результат.ВремяПервойПропущенной = ВремяСоздания;
				КонецЕсли;
				Продолжить;
			ИначеЕсли Статус <> "DONE" Или Транзакция["reverse"] = Истина Тогда
				// DECLINED и сторно в учет не идут (§6 спеки).
				Продолжить;
			КонецЕсли;
			
			Если ДобавленныеИдентификаторы[Транзакция["id"]] <> Неопределено Тогда
				Продолжить;
			КонецЕсли;
			ДобавленныеИдентификаторы.Вставить(Транзакция["id"], Истина);
			
			Результат.Транзакции.Добавить(Транзакция);
			
			ВремяПроведения = ДатаИзUnixTime(?(Транзакция["completedTime"] = Неопределено, Транзакция["time"], Транзакция["completedTime"]));
			Если ВремяПроведения > Результат.ВремяПоследнейЗагруженной Тогда
				Результат.ВремяПоследнейЗагруженной = ВремяПроведения;
				Результат.ИДПоследнейЗагруженной = Транзакция["id"];
			КонецЕсли;
			Если ДобавленныеДаты[НачалоДня(ВремяПроведения)] = Неопределено Тогда
				ДобавленныеДаты.Вставить(НачалоДня(ВремяПроведения), Истина);
				Результат.ДатыЗагруженных.Добавить(НачалоДня(ВремяПроведения));
			КонецЕсли;
			
		КонецЦикла;
		
		Если Страница.Количество() < РазмерСтраницы() Тогда
			Прервать;
		КонецЕсли;
		Если ВремяСамойРанней = Неопределено Или ВремяСамойРанней <= НачалоПериода Тогда
			Прервать;
		КонецЕсли;
		ВерхняяГраница = ВремяСамойРанней;
		
	КонецЦикла;
	
	Возврат Результат;
```
