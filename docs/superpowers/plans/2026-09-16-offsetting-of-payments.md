# Залік платежів: єдина логіка `СпособЗачетаТЧ` — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Одна експортна процедура менеджерного модуля `СМП_КлиентБанк` визначає `СпособЗачетаТЧ` рядка ТЧ `Загрузка` для інтерактивного й регламентного режимів за правилами УНФ; налаштування `Объект.СпособЗачета` і всі дублі логіки прибираються.

**Architecture:** Логіка живе в `ManagerModule.УстановитьСпособЗачетаТЧ(СтрокаДокумента)` і предикаті `ЭтоОперацияГдеВозможныАвтоРасчеты(ВидОперации)` (чотири види операцій). Її кличуть: блок «Способ зачета» у `РаспознатьДанныеВСтрокеДокумента` менеджера, той самий блок у локальних копіях розпізнавання в модулях Приват і NovaPay (регламент), і серверні обгортки `ФормаЗагрузка` (зміна контрагента/договору/виду операції, «змінити спосіб у всіх рядках»). `ObjectModule.Загрузить` переносить `СпособЗачетаТЧ` у документ для тих самих чотирьох видів. Поле «Спосіб заліку» у `ФормаНастройка`, його збереження та передача параметрами — видаляються; реквізит `СМП_КлиентБанк.СпособЗачета` у метаданих лишається.

**Tech Stack:** 1С:Підприємство 8.3.27, розширення у форматі Designer platform XML, BSL, Unica MCP (`unica_cfe_validate`, `unica_form_edit`, `unica_form_validate`, `unica_runtime_execute`), git.

**Spec:** `docs/superpowers/specs/2026-09-16-offsetting-of-payments-design.md` (далі — «спека», посилання на розділи як §N).

## Global Constraints

- Продукт — лише `SMP_BankExchange_SMB`. SMBru і ACC не чіпати (спека §3).
- Формат вихідників — Designer platform XML; платформа `8.3.27.x`. EDT не використовується (CLAUDE.md).
- Сховище конфігурації — тільки читання; `git push`, PR — лише за явним проханням (CLAUDE.md).
- Усі застосовні операції Unica (`dryRun: false`) — з названим ризиком; у межах цього плану виконавець **один раз на старті** просить дозволу завантажувати розширення в базу агента (`operation=build`) після кожної задачі.
- Підрядки `лиценз`/`ліценз`/`license`/`HASP` у виводі платформи — стоп і доповідь (CLAUDE.md).
- Запозичені модулі УНФ `КлиентБанкВызовСервера` і `УправлениеНебольшойФирмойКлиент` **не чіпати** (спека §2.4) — вони й далі носять `СпособЗачета` у структурах, це усвідомлено.
- Модулі `СМП_РаботаСБанкамиМонобанкAPIСервер`, `…МонобанкЮрAPIСервер`, `…ПУМБAPIСервер`, обробки `СМП_ОбработкаВыпискиБанка_*` і `epf/` — не чіпати (спека §3): вони кличуть менеджер і зміну отримують автоматично.
- Реквізит `СМП_КлиентБанк.СпособЗачета` у `DataProcessors/СМП_КлиентБанк.xml` **не видаляти** (спека §2.4).
- Ручне перевизначення користувачем у `ФормаЗагрузка` (колонка «Спосіб заліку», `ЗагрузкаСпособЗачетаПриИзменении`, `ПриИзмененииСпособаЗачета`, `ОчиститьИнформациюОДокументахНаКлиенте`, `УстановитьСпособРаспределенияОплаты`) — **лишається** (спека §2.2).
- Множина видів операцій для `Авто` — рівно чотири: `ПоступлениеНаСчет.ОтПокупателя`, `ПоступлениеНаСчет.ОтНашейОрганизации`, `РасходСоСчета.Поставщику`, `РасходСоСчета.НашейОрганизации` (спека §2.1).
- Рядок, прив'язаний до існуючого документа (`СтрокаДокумента.Документ` заповнено) з непорожнім `РасшифровкаПлатежа[0].СпособЗачета`, бере спосіб з документа і не переобчислюється (спека §1.3, припущення; §2.1).
- Мова коду — як у сусідніх модулях: ідентифікатори й коментарі російською. Маркери змін у чужому коді обробки — `//СМП_РаботаСБанками +++` / `//СМП_РаботаСБанками ---`, як уже прийнято в `ManagerModule.bsl`.

```bsl
//СМП_РаботаСБанками +++
// Единая логика способа зачета для строки ТЧ "Загрузка" — интерактивный режим и регламент.
// Настройка обработки Объект.СпособЗачета в расчете не участвует.
//
// Параметры:
//   СтрокаДокумента - СтрокаТабличнойЧасти, ДанныеФормыЭлементКоллекции - строка ТЧ "Загрузка".
//     Читаются: Документ, ДокументРасчетов, ПлатежноеПоручение, СчетНаОплату, Заказ, ВидОперации,
//     Договор, Контрагент. Заполняется: СпособЗачетаТЧ.
//
Процедура УстановитьСпособЗачетаТЧ(СтрокаДокумента) Экспорт
	
	СпособЗачетаВручную = Перечисления.СпособыЗачетаИРаспределенияПлатежей.Вручную;
	
	// Строка привязана к существующему документу — способ берем из него, не пересчитываем.
	Если ЗначениеЗаполнено(СтрокаДокумента.Документ)
		И СтрокаДокумента.Документ.РасшифровкаПлатежа.Количество() > 0
		И ЗначениеЗаполнено(СтрокаДокумента.Документ.РасшифровкаПлатежа[0].СпособЗачета) Тогда
		СтрокаДокумента.СпособЗачетаТЧ = СтрокаДокумента.Документ.РасшифровкаПлатежа[0].СпособЗачета;
		Возврат;
	КонецЕсли;
	
	СтрокаДокумента.СпособЗачетаТЧ = Перечисления.СпособыЗачетаИРаспределенияПлатежей.Авто;
	
	Если ЗначениеЗаполнено(СтрокаДокумента.ДокументРасчетов)
		Или ЗначениеЗаполнено(СтрокаДокумента.ПлатежноеПоручение)
		Или ЗначениеЗаполнено(СтрокаДокумента.СчетНаОплату)
		Или ЗначениеЗаполнено(СтрокаДокумента.Заказ) Тогда
		// Найден документ расчетов — зачет вручную на него, как в типовой форме документа.
		СтрокаДокумента.СпособЗачетаТЧ = СпособЗачетаВручную;
	ИначеЕсли НЕ ЭтоОперацияГдеВозможныАвтоРасчеты(СтрокаДокумента.ВидОперации) Тогда
		СтрокаДокумента.СпособЗачетаТЧ = СпособЗачетаВручную;
	Иначе
		// Правила УНФ: договор -> контрагент -> константа СпособРазнесенияОплатыПоУмолчанию.
		// Еще не созданные контрагент/договор (в строке — Строка) передаются пустыми ссылками.
		Контрагент = ?(ТипЗнч(СтрокаДокумента.Контрагент) = Тип("СправочникСсылка.Контрагенты"),
			СтрокаДокумента.Контрагент, Справочники.Контрагенты.ПустаяСсылка());
		Договор = ?(ТипЗнч(СтрокаДокумента.Договор) = Тип("СправочникСсылка.ДоговорыКонтрагентов"),
			СтрокаДокумента.Договор, Справочники.ДоговорыКонтрагентов.ПустаяСсылка());
		СтрокаДокумента.СпособЗачетаТЧ = РасчетыРаботаСФормамиВызовСервера.СпособРазнесенияОплатыДляДоговора(Договор, Контрагент);
	КонецЕсли;
	
КонецПроцедуры

// Виды операций банковских документов, для которых УНФ распределяет оплату автоматически
// (банковская часть РасчетыПроведениеДокументов.ЭтоВидОперацииВзаиморасчетов).
//
Функция ЭтоОперацияГдеВозможныАвтоРасчеты(ВидОперации) Экспорт
	
	Возврат ВидОперации = Перечисления.ВидыОперацийПоступлениеНаСчет.ОтПокупателя
		Или ВидОперации = Перечисления.ВидыОперацийПоступлениеНаСчет.ОтНашейОрганизации
		Или ВидОперации = Перечисления.ВидыОперацийРасходСоСчета.Поставщику
		Или ВидОперации = Перечисления.ВидыОперацийРасходСоСчета.НашейОрганизации;
	
КонецФункции
//СМП_РаботаСБанками ---
```
