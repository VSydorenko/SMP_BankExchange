## Вимір `XBase` (задача 4)

**Умова:** 2026-10-14, база — файлова `SMP_BankExchange_SMB/build/ib` ворктрі (з DT, задача 0′).
Платформа гілки 8.3.27: на машині встановлено 8.3.27.1644 і 8.3.27.2342, базу розгорнуто
8.3.27.2342; яку з двох збірок `v8-runner` узяв для прогону зондів, не зафіксовано. Код зондів
виконувався в серверному контексті YaXUnit (`[Сервер]`). У файловому режимі це процес клієнта на
тій самій машині, а не окремий сервер 1С. ОС — Windows Server 2022, системна локаль `ru-RU`,
`ACP` = 1251, `OEMCP` = 866. Зонди — тимчасові тести в `СМП_ТестыЧтенияВыписок`, не закомічені.
Вхід — синтетичні DBF, реальних даних немає. Вимір зробив імплементатор задачі 4 до реалізації.

| Що виміряно | Сирий результат |
|---|---|
| Ім'я файлу | `СоздатьФайл` і `ОткрытьФайл` відхиляють ім'я файлу, довше за 8 символів: «Длина имени файла превысила 8 символов». Довжину шляху (каталогу) це не обмежує. Ім'я з `ПолучитьИмяВременногоФайла("dbf")` (`v8_xxxx_cN`, 10 символів) непридатне |
| Кодування | Є лише `КодировкаXBase.ANSI` і `OEM`, за замовчуванням `ANSI`. На цій ОС `ANSI` читає cp1251, `OEM` — cp866. Інших кодувань (utf-8, koi8-r) немає. Якщо байт мови в заголовку 0 (як у зразках), кодування береться з властивості, а не з файлу. Сам `XBase` пише байт мови: `ANSI` → `0xC9`, `OEM` → `0x65`. **Висновок, не вимір:** `ANSI`/`OEM` — кодові сторінки ОС, тож відповідність `windows-1251` → `ANSI` тримається лише на ОС з кириличною локаллю |
| Числове поле `N` | `"12.5      "`, `"   12.5"`, `"-7.25"` читаються правильно. Сміття стає числом без винятку: порожнє → 0, `"abc"` → 0, `"-"` → 0, `"1,5"` → 1, `"1e3"` → 1, `"12.50.1"` → 12.5 |
| Символьне поле з NUL | `a\0b` → `a` (довжина 1), значення обрізається на NUL без винятку |
| Дата `D` | Порожня, нулі, `"20241399"`, літери → порожня дата без винятку; `"2024031 "` → 10.03.2024 |
| Довге символьне поле | `S(420)`, `S(300)` створюються й читаються; значення доповнене пробілами до повної довжини (420); 16-бітна довжина в заголовку розпізнається, наступні поля не зсуваються |
| Вилучені записи | За замовчуванням (`ОтображатьУдаленные = Ложь`) пропускаються; `НомерЗаписи()` фізичний: запис після вилученого другого має номер 3 |
| Типи значень | `C` → Строка (з пробілами справа), `D` → Дата, `N` → Число |
| Зіпсований файл | Обрізаний посеред запису або заголовок обіцяє більше записів → виняток «Ошибка чтения из файла»; текст замість DBF → «Формат файла отличен от .DBF». Інших винятків під час читання не траплялось |
