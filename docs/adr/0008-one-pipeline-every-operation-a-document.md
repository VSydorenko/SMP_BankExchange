# ADR-0008: Один конвеєр для регламенту й інтерактиву; кожна операція — документ

Status: accepted 2026-10-12
Decided by: owner
Spec: `docs/superpowers/specs/2026-10-12-smb-import-platform-design.md` §3 D3, D4, D20, D32

## Context
Налаштування завантаження жили в трьох місцях з різними значеннями за замовчуванням. Стара обробка
мовчки пропускала операції, яким бракувало даних.

## Decision
Регламент і інтерактив викликають той самий код розпізнавання й запису; налаштування — лише в
обліковому записі банку. Регламент записує одразу, інтерактив — той самий конвеєр із паузою для людини.
Кожна банківська операція стає документом. Бракує даних — документ записується непроведеним. Причину
видно в журналі реєстрації (регламент) чи протоколі форми (інтерактив), на документі її немає. Новий
документ завжди пробує провестися.

## Why
Власник: пропущені грошові документи підривають довіру до інструмента, а непроведені бухгалтери
дозаповнюють з тексту призначення. Проводячи документ сам, бухгалтер бачить помилку вендора.

## Rejected
- Мовчазний пропуск рядка.
- Окремі налаштування для регламенту.
- Прапорець «проводити завантажені».
- Збережена історія запусків регламенту.

## Consequences
Відмова — лише коли документ не можна навіть записати. Запис іде поза транзакцією виклику, щоб відмова
одного документа не зламала пакет.
