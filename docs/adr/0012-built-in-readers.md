# ADR-0012: Вбудовані читачі — модуль на формат, реєстр у коді, еталон — стара обробка

Status: accepted 2026-10-13
Decided by: owner
Spec: `docs/superpowers/specs/2026-10-12-smb-import-platform-design.md` §3 D30; `docs/architecture/readers.md`

## Context
Кілька банків віддають той самий файл, а один банк — кілька форматів. Документи старої обробки вже лежать
у базах клієнтів.

## Decision
Читач — модуль на формат над спільними контейнерами (CSV, фіксовані позиції, DBF, XML). Реєстр «банк +
формат» живе в коді, ідентифікатор рядка ніколи не перевикористовується. Банк з API отримує лише
конектор, без файлового читача. DBF розбирається власним кодом. Еталон поведінки — стара обробка;
відступ від неї — лише іменованим рішенням із лічбою.

## Why
Формат не дорівнює банку. `XBase` дає мовчазні спотворення. Поведінка, відмінна від старої, дала б
дублі вже завантажених документів.

## Rejected
- Декларативний читач — виконує код з налаштувань і ковтає помилки.
- Файловий читач для банку з API.
- «Очевидні покращення» без лічби.

## Consequences
Модуль викликається явним диспетчером за іменем у тексті, щоб компілятор бачив кожен виклик.
