# ADR-0004: Ідентифікатор операції банку — власний реквізит `СМП_ИДТранзакцииБанка`

Status: accepted 2026-09-15
Decided by: architect
Spec: `docs/superpowers/specs/2026-09-15-monobank-fop-tov-design.md`

## Context
monobank віддає ідентифікатор операції, довший за `НомерВходящегоДокумента`. Без збереженого
ідентифікатора повторне завантаження дає дублі.

## Decision
Документи `ПоступлениеНаСчет` і `РасходСоСчета` отримують реквізит розширення `СМП_ИДТранзакцииБанка`
(рядок 50, індексований). Ідентифікатор, довший за 50 символів, — помилка на межі контракту, а не
обрізання.

## Why
Розширення 1С не дозволяють змінювати тип і довжину запозичених реквізитів. Обрізаний ідентифікатор не
впізнав би сам себе при повторному завантаженні.

## Rejected
- Подовжити `НомерВходящегоДокумента` — заборонено платформою для запозичених реквізитів.
- Обрізати ідентифікатор — тихі дублі.

## Consequences
Ключ впізнавання нової платформи стоїть на цьому реквізиті (ADR-0013).
