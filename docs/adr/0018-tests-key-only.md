# ADR-0018: Тести — окреме розширення, лише ключове, зразки лише знеособлені

Status: accepted 2026-11-04
Decided by: owner
Spec: `docs/superpowers/specs/2026-10-12-smb-import-platform-design.md` §3 D22; `docs/architecture/testing.md`

## Context
Тестові модулі кличуть API YaXUnit, якого в клієнта немає. Реальна виписка містить рахунки, коди й назви
клієнтів, а репозиторій публічний. На етапі 6 тестів було більше, ніж коду.

## Decision
Тести YaXUnit живуть в окремому розширенні `SMP_BankExchange_SMB_Tests`, поза постачанням. Головна
перевірка — приймання власником у дев-базі на його даних. Постійні тести — лише контракт, інваріант
безпеки й харнес; поведінку перевіряє тимчасовий тест, висновок — у журнал. Зразки виписок у git лише
знеособлені інструментом, еталон рахує незалежний оракул, мапа «реальне → вигадане» — поза git.

## Why
Власник: «тести устаріють з оновленням релізу» і «тестувати тільки ключове та критично важливе».
Тест, що сам задає умову, яку міряє, нічого не доводить.

## Rejected
- Тестовий код у постачальному `.cfe`.
- Широке покриття поведінки вендора.
- Сирі виписки в макетах.

## Consequences
Червоний тест характеризації вендора після оновлення УНФ означає «перемірити», а не «зламано».
