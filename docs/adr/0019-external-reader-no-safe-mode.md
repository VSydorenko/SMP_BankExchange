# ADR-0019: Зовнішня обробка-читач підключається через БСП без безпечного режиму

Status: accepted 2026-10-12
Decided by: architect
Spec: `docs/superpowers/specs/2026-10-12-smb-import-platform-design.md` §3 D31; `docs/architecture/reader-contract.md`

## Context
Сторонні читачі підключаються через `ДополнительныеОтчетыИОбработки` БСП. Більшість нинішніх обробок
`epf/` пишуть вхідні дані в тимчасовий файл.

## Decision
Зовнішня обробка-читач створюється без безпечного режиму, як зараз. Значення режиму задано в одному
місці коду. Відповідальність за обробку несе адміністратор, який її додав.

## Why
Безпечний режим, за документацією, забороняє роботу з файлами; це не виміряно.

## Rejected
- Безпечний режим для сторонніх читачів (поза обсягом).

## Consequences
Рішення може змінитись: тоді змінюється одне місце коду, а вбудовані читачі не зачеплені — вони читають
з пам'яті.
