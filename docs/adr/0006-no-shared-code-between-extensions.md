# ADR-0006: Між розширеннями немає спільного коду; перенесення — копією після стабілізації

Status: accepted 2026-10-12
Decided by: owner
Spec: `docs/superpowers/specs/2026-10-12-smb-import-platform-design.md` §3 D9, D29

## Context
Три розширення (SMB, SMBru, ACC) мають однакову підсистему. Двічі пропонували спільне ядро:
окреме розширення або спільне джерело в git зі скриптом синхронізації в кожне `cfe/src`.

## Decision
Кожне розширення самодостатнє, зі своїм сховищем. Рішення робиться в SMB, а в SMBru і ACC
переноситься копією після стабілізації внутрішнього API. Переносимість забезпечує контракт, що
спирається лише на типи платформи (ADR-0011), а не інфраструктура.

## Why
Виклики між розширеннями працюють лише в режимі підприємства: у Конфігураторі розширення ізольовані,
синтаксичний контроль не працює, типи не передаються. Зворотна синхронізація «Конфігуратор → сховище →
git» зі спільним кодом не працює.

## Rejected
- Розширення-ядро.
- Спільне джерело в git плюс синхронізація.

## Consequences
Питання закрите двічі; не пропонувати знову. Модулі-«ворота» не називають об'єктів конфігурації, щоб
копія лягала без правок.
