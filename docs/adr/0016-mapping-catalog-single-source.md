# ADR-0016: Довідник відповідностей — єдине джерело правил за текстом; історія вибору прибрана

Status: accepted 2026-10-12
Decided by: owner
Spec: `docs/superpowers/specs/2026-10-12-smb-import-platform-design.md` §3 D11, D24; `docs/architecture/recognition.md`

## Context
Стара обробка писала «історію вибору значень» для кожного рядка, і вона перебивала довідник: помилкове
розпізнавання закріплювалось само собою. Ключові слова були вшиті в код, тож позначку «Перевірте
операцію» отримував майже кожен платіж.

## Decision
Правила розпізнавання за текстом призначення живуть лише у вендорському довіднику
`СоответствияНазначенийПлатежаИРеквизитовПлатежа`. Вшитих слів у коді немає; типові правила — дані, які
людина бачить і править. Історія вибору не пишеться й не читається. Збіг — підрядок без регістру, перше
правило за кодом виграє.

## Why
Користувачі вже працюють із довідником. Правила клієнтів стоять на семантиці «підрядок без регістру»,
тож її не змінюють.

## Rejected
- Вшиті фрази в коді.
- Історія вибору чи прапорець «аналіз історії».

## Consequences
Регістр історії можна прибрати разом зі старою обробкою; його дані зникнуть, це прийнятно. «Перевірте
операцію» означає рівно одне: жодне джерело виду не спрацювало.
